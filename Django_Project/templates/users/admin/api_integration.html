Endpoint 1: Real-Time Review Detection
POST /api/analyze-review/

Feed single reviews from external e-commerce platforms (Shopify, WooCommerce, custom web stores) to compute real-time authenticity scores using LinearSVC, J-48 C4.5, and NLP sentiment polarity.

Request JSON Payload:
{
    "text": "Extremely satisfied with this laptop! Battery life lasts 20 hours easily and keyboard is responsive.",
    "rating": 5,
    "ip": "203.0.113.195"
}
Response JSON:
{
    "svm_score": 92.4,
    "j48_score": 88.0,
    "sentiment_polarity": 0.45,
    "ip_flag": false,
    "final_score": 90.2,
    "label": "Genuine",
    "status": "success"
}
Python Client Implementation
import requests

API_URL = "http://127.0.0.1:8000/api/analyze-review/"

payload = {
    "text": "Worst purchase ever broke immediately!",
    "rating": 1,
    "ip": "192.168.1.100"
}

response = requests.post(API_URL, json=payload)
data = response.json()

print(f"Classification: {data['label']}")
print(f"Authenticity Score: {data['final_score']}%")
cURL Shell Command
curl -X POST http://127.0.0.1:8000/api/analyze-review/ \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Great wireless mouse, zero lag.",
