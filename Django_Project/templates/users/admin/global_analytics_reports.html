E-Commerce REST API Integration Endpoint
Documentation and payloads for third-party stores feeding reviews into Graze Smasher
Active REST API
POST /api/analyze-review/

Feed single reviews from external e-commerce stores (Amazon, Shopify, WooCommerce) to compute real-time authenticity scores using LinearSVC, J-48 C4.5, and NLP sentiment polarity.

Request JSON Payload:
{
    "text": "Extremely satisfied with this laptop! Battery life lasts 20 hours easily and keyboard is responsive.",
    "rating": 5,
    "ip": "203.0.113.195"
}
Response JSON:
{
    "svm_score": 92.4,
    "j48_score": 88.0,
    "sentiment_polarity": 0.45,
    "ip_flag": false,
    "final_score": 90.2,
    "label": "Genuine",
    "status": "success"
}
Python Integration Example:
import requests

url = "http://127.0.0.1:8000/api/analyze-review/"
payload = {
    "text": "Super fast shipping, product works as expected!",
    "rating": 5,
    "ip": "192.168.1.10"
}
response = requests.post(url, json=payload)
data = response.json()
print("ML Classification:", data["label"], "Score:", data["final_score"])
