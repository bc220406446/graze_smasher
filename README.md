# Graze Smasher Product Hunting Tool - Fake Review Detection System

This prototype demonstrates a complete end-to-end Machine Learning pipeline for detecting fake product reviews. The system uses Natural Language Processing (NLP) techniques to preprocess reviews, feeds them into a Support Vector Machine (SVM) classifier, and presents a user-friendly prediction interface via a Django web application.

## Machine Learning Pipeline

### 1. Dataset Collection
The system leverages the **Salminen et al. Fake Reviews Dataset** containing balanced product reviews categorized as:
*   **Genuine (OR - Original)**: Authentic customer reviews.
*   **Fake (CG - Computer Generated)**: Synthetic reviews generated by text generation algorithms.

A balanced subset of **10,000 reviews** (5,000 CG, 5,000 OR) is extracted and saved to `Dataset/fake_reviews_dataset.csv`.

### 2. Preprocessing
To clean and prepare raw reviews, `ML_Model/preprocess.py` implements:
1.  **Lowercase Conversion**: Normalizes text case.
2.  **Punctuation Removal**: Filters out special characters and symbols.
3.  **Tokenization**: Splits sentences into tokenized words using NLTK.
4.  **Stop-word Removal**: Excludes common English words using NLTK's list.
5.  **Lemmatization**: Reduces words to their core semantic lemma utilizing NLTK WordNet.

**Example**:
*   *Original*: `"This product is ABSOLUTELY amazing! I bought it for $19.99 and it's working flawlessly."`
*   *Preprocessed*: `"product absolutely amazing bought 19 99 working flawlessly"`

### 3. Model & Feature Representation
*   **Vectorization**: Term Frequency-Inverse Document Frequency (`TfidfVectorizer`) with an n-gram range of `(1, 2)`.
*   **Algorithm**: Support Vector Machine (`LinearSVC`) with standard regularization parameter $C=1.0$.
*   **Split**: 80% Train (8,000 samples) and 20% Test (2,000 samples).
*   **Evaluation Metrics**:
    *   **Accuracy**: 89.15% (Exceeds the 80% prototype target)
    *   **Precision**: 89.16%
    *   **Recall**: 89.15%
    *   **F1-Score**: 89.15%

## Setup & Running Instructions

### Prerequisites
*   Python 3.10+ (Standard Python environment or managed via package managers like `uv`)

### Installation & Environment Setup
To setup dependencies and run the prototype:
1.  Navigate to the project root:
    ```bash
    cd graze_smasher
    ```
2.  Create virtual environment and install packages:
    ```bash
    python -m venv .venv
    # Activate virtual environment
    # Windows Command Prompt:
    .venv\Scripts\activate.bat
    # Windows PowerShell:
    .venv\Scripts\Activate.ps1
    # Unix/macOS:
    source .venv/bin/activate

    # Install dependencies
    pip install django pandas scikit-learn nltk joblib notebook nbconvert playwright openpyxl
    ```
3.  Download NLTK assets:
    ```bash
    python -c "import nltk; nltk.download('stopwords'); nltk.download('punkt'); nltk.download('punkt_tab'); nltk.download('wordnet')"
    ```

### Execution Steps
1.  **Download the dataset**:
    ```bash
    python Dataset/download_dataset.py
    ```
2.  **Train the Machine Learning model**:
    ```bash
    python ML_Model/train_model.py
    ```
    This trains the SVM classifier and saves serialized models inside `Trained_Model/`.
3.  **Run the Django Web Application**:
    ```bash
    cd Django_Project
    python manage.py migrate
    python manage.py runserver
    ```
    Open your browser and navigate to: `http://127.0.0.1:8000/`.

### Notebook and Screenshot Commands

After the one-time environment setup, run these commands from the project root when you need to recreate the notebook, export it as HTML, or capture the project screenshots:

1. **Create the Jupyter Notebook**:

   ```powershell
   python Notebook\create_notebook.py
   ```

2. **Convert the notebook to HTML**:

   ```powershell
   jupyter nbconvert --to html Notebook\fake_review_detection.ipynb --output-dir Notebook
   ```

3. **Capture screenshots**:

   ```powershell
   python generate_screenshots.py
   ```

The HTML file must be created before running `generate_screenshots.py`. The screenshot script opens the notebook HTML and the Django web interface, then saves images in the `Screenshots/` folder.

### After One-Time Setup

After the dataset and trained model have been prepared, you only need to start the Django server.

**If the virtual environment is not active**, run these commands from the project root:

```powershell
.\\.venv\\Scripts\\python.exe Django_Project\\manage.py runserver
```

**If the virtual environment is already active** (for example, VS Code activated `.venv` automatically after installing or configuring the Python extension), the terminal will show `(.venv)`. Run the same commands:

```powershell
cd Django_Project; python manage.py runserver
```

Open `http://127.0.0.1:8000/` in your browser and if you want to stop the server then Press `Ctrl+C` in the terminal.
